I ran into this while trying to figure out how far I could relax QuartiCal's dependencies. The following should reproduce (with `dask>=2025.4.0`):
```python
import dask.array as da
from dask.graph_manipulation import clone
from daskms import xds_from_storage_table

spw = xds_from_storage_table(
    "path/to/ms::SPECTRAL_WINDOW",
    columns=["CHAN_WIDTH"]
)[0]
da.compute(clone(spw.CHAN_WIDTH.data))
```
The problem seems to have been introduced in `dask==2025.4.0`. Have not done any digging on the `dask-ms` side to figure out why it is only surfaced in this specific case.
